01/What it does

Two tabs. Two questions answered.

Is my PC running too hot? And is anything running that shouldn't be? ThermoForge answers both, live.

Hardware tab

Live temperatures, with history

  • CPU, GPU, drives, RAM, battery and motherboard sensors, updated live
  • Summary cards coloured by status: normal, warm, hot
  • Rolling temperature history chart, with the sensors you choose
  • Session minimum and maximum for every sensor
  • Falls back to Windows thermal zones when not run as administrator
Processes tab

A process list that flags malware-like behaviour

  • Every running process, refreshed every 3 seconds, with CPU, memory, publisher and parent
  • Digital signature check for each program, including Windows catalog and MSIX packages
  • Flags fake Windows process names, unsigned programs in Temp folders, tampered signatures, encoded PowerShell and Office apps launching shells
  • A badge on the tab shows how many medium and high findings there are
  • Search, show only flagged, open file location, copy path, search online, end process (critical Windows processes are protected)

02/Process checks

What it looks for.

Each process is checked every 3 seconds. Findings are hints, not verdicts: every rule has innocent explanations, so treat a flag as a reason to look closer.

A Windows process name (svchost, lsass…) running from outside System32

High

A name one character off a Windows process, like scvhost.exe

High

Invalid or tampered digital signature

High

Unsigned and running from Temp, Public, the Recycle Bin or the root of AppData / ProgramData

High

Encoded PowerShell, download-and-run commands, misuse of mshta, certutil, regsvr32 or rundll32

High

An Office app starting cmd, PowerShell or a script host

High

Running from a suspicious folder (one level lower if signed)

Medium

Hidden-window PowerShell, Base64 decoding, a browser starting a script host

Medium

Unsigned program in a normal location; execution-policy bypass

Low

Signatures are verified with Windows' own WinVerifyTrust. Revocation is not checked, so no network access is needed.

04/Requirements

What you need to run it.

Requirements
  • Operating systemWindows 10 / 11 (x64)
  • Runtime.NET 10
  • RecommendedAdministrator rights
  • For CPU temperaturesPawnIO driver

Without administrator rights, CPU, motherboard and RAM sensors are unavailable, and Windows hides the path and command line of system processes.

Run from source 
# PowerShell
git clone https://github.com/gaaloulv36/thermoforge.git
cd thermoforge
dotnet run --project src/ThermoForge.UI
